# ⚔ PEO Battle Card AI

An AI-powered sales tool that helps PEO sales reps handle prospect objections in real time. Type an objection you just heard, pick the competitor you're up against, and get an instant battle card generated by Claude AI.

## Demo

![Battle Card AI](https://via.placeholder.com/800x400?text=PEO+Battle+Card+AI)

## Features

- **Competitor selector** — ADP TotalSource, Paychex, Insperity, TriNet, Justworks
- **Quick pick objections** — tap common objections to load them instantly
- **AI-generated battle card** with 4 sections:
  - ↺ **Reframe** — flips the objection into an opportunity
  - ⚡ **Counter Points** — 3 specific talking points
  - 🎯 **Trap Question** — a question that reveals hidden pain
  - → **Close Line** — a confident transition to move forward
- **History tab** — saves your last 15 counters

## Tech Stack

- **Frontend:** React, Vite
- **Backend:** Node.js, Express
- **AI:** Anthropic Claude API
- **Styling:** Inline styles, CSS animations
